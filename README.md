Smoothie Bar:
An interactive smoothie builder made for the Nony Corp Web Design Cohort II final project. The user picks a base liquid, fruits and an optional protein add-on, and the page updates live with an ingredients list and a total calorie count.

Features:
*Choose a base liquid: Milk or Water
*Choose fruits: Banana, Strawberry, Mango, Pineapple, Blueberry
*Choose whether to add protein
*"Ingredients Cup" lists every selected item with its calories
*Total calories update as the user clicks
*Reset button clears all choices and sets the total calories back to 0

Built With:
*HTML
*CSS (Flexbox, no external libraries)
*JavaScript

**Live demo:** [https://j-agyeiwaa.github.io/final-project/](https://j-agyeiwaa.github.io/final-project/)

How to Run:
*Download or clone this repository
*Open index.html in your browser
